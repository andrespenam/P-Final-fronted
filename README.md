---

## 📌 Descripción

Panadería D’Pieri es una **app web creada como proyecto final de curso**, pensada para ofrecer **una experiencia de compra online de productos de panadería** de manera rápida, moderna y atractiva.

Los usuarios pueden:

- 🌟 Explorar productos frescos de panadería  
- 🛒 Agregar productos al carrito y realizar pedidos  
- 👤 Registrarse e iniciar sesión  
- 📞 Contactar a la panadería  
- 🏠 Conocer sobre la empresa  

---

## ⚡ Funcionalidades

- ✅ Navegación con React Router DOM  
- ✅ Login y registro de usuarios  
- ✅ Carrito de compras dinámico  
- ✅ Navbar dinámico según estado de sesión  
- ✅ Alertas visuales con SweetAlert2  
- ✅ Diseño responsive con React Bootstrap  
- ✅ Actualización en tiempo real de la sesión con React Context  
- ✅ Animaciones y vídeos de fondo 🎥
